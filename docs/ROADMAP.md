# 直播操盘台开发与验收清单

核对日期：2026-11-09。首个交付目标是在 **macOS Apple Silicon** 上可安装、可启动、可维护的本机工作台，由 GitHub 管理源码、任务、测试和版本。

“全部完成”以本清单中的用户流程和验收结果为准：按钮可用、数据真实、失败可恢复、能够在另一台目标电脑安装。完成界面、存在接口或测试通过，都不单独等于业务已经验收。

## 范围与状态

- **已有实现**：源码中有可调用的实现；仍可能缺少真实环境验收。
- **已验证部分流程**：已有本机操作或真实数据核对记录，验证范围必须说明。
- **待开发**：流程或实现尚不存在。
- **待用户配置**：需要账号、表格、目标账户或数据权限，不能用测试数据替代验收。

本轮完整化范围包括现有六个页面，以及已提出的千川消耗、历史报表、场次复盘、飞书同步和 Ego 后台辅助流程。飞瓜分析所得的全部任务只是候选清单；改价、评论发送、商品上下架、投放预算调整等主动业务操作不在本版范围。第三方数据源仅在有可用授权接口或用户可导出的报表时实现；未能接入的项目保留为“未完成 / 待条件”，不能改成“已连接”。

GitHub 托管的是代码和开发记录。录制、浏览器登录和定时采集依赖运行中的本机服务；GitHub Pages 或 Actions 不代替持续录制服务。账号会话、密钥、录屏、字幕、数据库和真实经营报表保留在本机。

## 关键子系统

### 录屏后处理

已有顺序：录制文件稳定 → 压缩 MP4 → 全片解码校验 → 按设置删除对应原件 → 可选语音转写。用户目标是保留压缩视频及 TXT / SRT，成功校验后删除未压缩视频。缺省配置保留原件，已有配置才决定是否删除。

- [ ] 在新电脑上发现或安装 FFmpeg、whisper.cpp 和指定模型。
- [ ] 对真实短场次验收压缩视频可播放，字幕和文本可打开，音画与时间轴可对应。
- [ ] 磁盘不足、编码失败、校验失败、源文件变化、转写失败可解释且可恢复；禁止误删源文件或重复压缩压缩产物。
- [ ] 任务重试、失败状态和产物入口完整；转写失败不丢失已经校验成功的压缩视频。

### Ego 后台辅助

现有 `Ego 后台接入进度` 是上次核验的只读记录，**没有后台浏览器适配器或定时 Ego 采集器**。Ego 同一 profile 的页面共享登录，不能自动等同于 Chrome 的独立多账号采集会话。

- [ ] 集成固定后台入口、账号核对、可接管的任务状态与结果回写。
- [ ] 区分浏览器可用、已登录、账号匹配、数据可读、历史核验记录；不得把打开网页当连接成功。
- [ ] 报表下载 / 导入可检查格式、账号、日期范围及重复数据；取消或登录过期可以安全重试。
- [ ] 人工扫码及授权时明确交还控制权，用户确认后再继续；账户切换不能混入其他账号的数据。

千川广告账户选择目前按用户要求暂停。其他开发可继续；不得自动恢复选户或据相似名称猜测账户绑定。

### 历史数据与复盘

- [ ] 支持日期筛选、分页 / 限额、历史场次回填和重复导入处理。
- [ ] 统一场次键，关联直播数据、视频分段、字幕和消耗；跨日场次不拆错。
- [ ] 首先提供基于已验证数据的汇总、比较和异常提示；AI 总结为后续可选能力，需要模型 / 服务配置及数据使用方式明确。
- [ ] 每个结论可回到原数据或录屏时间点；没有证据时显示缺失，不生成虚构指标。
- [ ] 复盘结果可以保存、再次打开和导出；实时数据与最终数据标明版本和采样时间。

## 开发顺序

### P0：仓库与可复现启动

1. 建立私有仓库，提交经过筛选的应用代码、依赖清单、说明和测试。仓库已创建，首版推送与 CI 结果以提交记录为准。
2. 排除个人文件、反查资料、真实报表、浏览器会话和运行目录；测试夹具使用虚构 ID。
3. 提供环境检查、标准启动、依赖安装和故障定位步骤，减少对某台机器内置运行时的依赖。
4. CI 执行单元 / HTTP 测试和语法检查；在未安装浏览器、未登录平台的环境仍可完成测试。
5. 在另一台目标 Mac 从干净 checkout 启动验证；形成版本号与变更记录。

### P1：补齐已有功能闭环

修复无响应的导出入口、过时状态文案及来源混淆；完成目录与依赖检测、录制后处理真实验收、错误恢复。优先做到现有页面里的每个按钮都能完成其宣称的动作。

### P2：打通经营数据与同步

完成罗盘指标真实校验、千川消耗采样、历史场次回填和飞书真实同步。字段规范必须先于趋势合计、复盘计算和外部写入。

### P3：复盘与语料洞察

建立场次关联、历史报表导入、字幕搜索、关键词提取、复盘保存 / 导出，再考虑模型辅助总结。第三方数据源按授权与接口可用性逐项推进。

### P4：发布与迁移

完整运行一场获授权直播及一次历史报表流程，验证重启恢复和跨电脑安装；发布可追溯版本、安装文档及已知限制。待权限项目保持未完成，不用演示数据宣告交付。
